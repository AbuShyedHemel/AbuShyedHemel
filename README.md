### What I work on

- **Multi-module product surfaces** — shared component libraries and layout primitives that stay consistent across a dozen-plus feature modules
- **Configuration-driven UI** — panels and forms where behaviour is defined by schema rather than hardcoded, so non-engineers can extend them
- **Performance and rendering** — keeping large tables, dashboards, and nested forms responsive as data volume grows
- **Front-end architecture** — state boundaries, data-fetching patterns, and the routing decisions that stop a codebase from ossifying
